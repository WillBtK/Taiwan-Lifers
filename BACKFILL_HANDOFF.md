# Hedge Ratio Backfill — Handoff to Haiku 4.5

## Overview

This task fills in the Insurance Bureau's monthly hedge ratio data for 2020-01 → 2025-07 (67 months). This is load-bearing for Stage 2: without hedge principal (ratio × denominator), sector-level series 1, 2, 5 cannot be derived before 2026.

**Status:** Infrastructure ready. Article search and collection required.

## What's in place

1. **Template config** (`config/briefing_press_backfill.json`): Generated by `scripts/backfill_hedge_ratio_search.py`. Has 67 row templates (one per month) with empty URL, fields, and quote fields.

2. **Verification script** (`scripts/verify_backfill_articles.py`): Takes a URL and month, fetches the article, extracts and verifies figures, outputs a config fragment ready to paste into the template.

3. **Strategy document** (`docs/BACKFILL_STRATEGY.md`): Complete context including search patterns, data fields, identity checks, and workflow.

4. **Reference config** (`config/briefing_press.json`): 11 months of complete 2024-12 and 2026 data showing the exact format. Run `scripts/stage1_briefing_press.py` to verify and generate SQL.

## Your task (Haiku)

For each of the 67 months (2020-01 → 2025-07), identify one article from `money.udn.com` (or secondary sources cnyes.com, CTS/CNA) citing the Insurance Bureau's monthly briefing, and extract:

### Primary field (required)
- `hedge_ratio_regulatory`: Hedge ratio as printed (e.g., "50.23%")

### Secondary fields (if available, strengthen the backfill)
- `regulatory_fx_exposure`: Exposure after FX-policy deductions (e.g., "15.4兆元")
- `foreign_investments`: Gross foreign investment (e.g., "22.8兆元")
- `fx_reserve_total`: FX volatility reserve balance (e.g., "6,137億元")

### How to search

1. **For each month YYYY-MM:**
   - Search: `site:money.udn.com 保險局 避險比率 YYYY年M月` (or similar keyword variants)
   - Alternative outlets if money.udn.com articles are missing: `news.cnyes.com`, `news.cts.com.tw`
   - Articles are typically published within 1–2 weeks of month-end
   - Look for the earliest, most authoritative article

2. **Once you have a URL:**
   - Run: `python3 scripts/verify_backfill_articles.py --month YYYY-MM --url "https://..."` to fetch and preview
   - Extract the exact quote containing the figures
   - Add the complete source entry to `config/briefing_press_backfill.json`:
     ```json
     {
       "obs_month": "YYYY-MM-01",
       "reported_by": "金管會保險局",
       "sources": [
         {
           "url": "https://money.udn.com/...",
           "published": "YYYY-MM-DD",
           "outlet": "經濟日報",
           "fields": {"hedge_ratio_regulatory": "NN.NN%"},
           "quote": "Exact quote with all figures"
         }
       ],
       "note": "…"
     }
     ```

### Denominator handling

- **2020, 2021, 2022, 2023, 2024, 2025 year-ends:** Extract `regulatory_fx_exposure` from the articles (all year-end briefings state this).
- **Monthly values for 2020–2024:** Year-end denominators only are typically available. Flag interpolated months with `"note": "Denominator interpolated from year-end"` so Stage 2 can decide whether to use interpolation or CBC foreign-asset data.
- **2025 monthly values:** Try to find monthly denominators from the briefing articles (they may be available from 2025-01 onwards if the Bureau expanded disclosures).

### Testing

Once you have completed the config:

1. Merge `config/briefing_press_backfill.json` into `config/briefing_press.json` (keep existing 2026 rows, add backfill rows in chronological order).

2. Run the verification:
   ```bash
   python3 scripts/stage1_briefing_press.py --refresh
   ```

3. Check the output:
   - `data/sector_monthly_briefing.csv`: Should have 67 + 11 = 78 rows (all months)
   - `reports/stage1_briefing_YYYYMMDD.json`: Check `verification_failures` (should be empty) and `checks` (should all pass with tolerance < 3%)
   - `out/stage1_briefing_YYYYMMDD.sql`: Idempotent INSERT statements

4. If all checks pass, apply SQL:
   ```bash
   # Via Supabase MCP (when credentials are available):
   cat out/stage1_briefing_YYYYMMDD.sql | supabase exec --write
   ```

## Known gaps and constraints

1. **2020-2024 monthly denominators:** Likely interpolated only; year-ends available from briefings. Flag basis.
2. **Historical article accessibility:** Articles from 2020-2024 may be archived or paywalled on some outlets; fallback to secondary sources or press databases if needed.
3. **Article structure varies:** Quote format and field location may differ across years and outlets; extract the exact printed figures.
