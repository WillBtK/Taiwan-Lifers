# Press-Reported Hedge Ratio Backfill (2020-01 → 2025-07)

## Load-bearing dependency

Stage 2 derives sector-level series 1 (economic ratio), 2 (net position) and 5 (gross ratio) using hedge principal = regulatory ratio × denominator. The monthly release (tlfx.sector_monthly channel `release`) gives hedging P&L but never the hedge principal. For 2020–2025, only the Insurance Bureau's monthly briefing carries both the hedge ratio and the sector denominator. Without this backfill, pre-2026 sector series 1/2/5 rely on the six-firm panel alone (insufficient per STATUS.md).

## Collection strategy

**Source.** Insurance Bureau's monthly press briefing on regulatory hedge ratios and FX exposure. Reported by major outlets within 1–2 weeks of month-end:
- Primary: `money.udn.com` (Economic Daily, most reliable)
- Secondary: `news.cnyes.com`, CTS/CNA (used in 2026 config as fallback)

**Search pattern.** For each month 2020-01 to 2025-07 (67 total):
- Month-end date is typically 1st of the following month (e.g., 2020-01-31 briefing → Feb article)
- Search terms: `保險局` (Insurance Bureau), `避險比率` (hedge ratio), `國外投資` (foreign investment)
- Article typically published on economic/finance section of the outlet

**Primary figures to extract.** Every article must carry:
- `hedge_ratio_regulatory`: Stated regulatory hedge ratio (e.g., "50.23%")

**Secondary figures** (if available, strengthen the backfill):
- `regulatory_fx_exposure`: Sector foreign-investment exposure after FX-policy deductions (e.g., "15.4兆元")
- `foreign_investments`: Gross foreign-investment total (e.g., "22.8兆元")
- `fx_reserve_total`: Sector FX volatility reserve balance (e.g., "6,137億元")

**Denominator handling.** The regulatory exposure is given at all month-ends in the briefing. Year-end exposures (2020, 2021, 2022, 2023, 2024, 2025) are stated directly. Monthly exposures for 2020–2024 are interpolations (flag basis as `interpolated_from_year_end`); 2025 monthly values should be available from the briefing. Interpolation method: 
- If month-end figures are published: use directly, basis = `disclosed`.
- If only year-ends available: linear interpolate between year-end values, basis = `interpolated_from_year_end`. Stage 2 will flag these for review against CBC foreign assets if needed.

## Data collection steps

1. **Search and record URLs** (suitable for Haiku web search).
   - For each month, identify the earliest article from money.udn.com citing the briefing.
   - Record exact URL (e.g., `https://money.udn.com/money/story/5613/{ID}`).
   - Record publication date and outlet.

2. **Extract figures and quotes** (config format in config/briefing_press.json).
   - Fetch the article, extract the paragraph containing the hedge ratio.
   - Record the exact printed figures and quote text.
   - Parse units: 兆 = ×1,000,000 (NT$ mn), 億 = ×100 (NT$ mn), % as fraction.

3. **Verify and test**.
   - Run `scripts/stage1_briefing_press.py --refresh` on the completed config to verify:
     - Every figure appears in its cited article (verification check).
     - Identity checks pass (net exposure ≈ regulatory exposure × (1 − ratio)).
     - CSV, SQL and report outputs are clean.

4. **Integrate into tlfx.sector_monthly** (via Supabase).
   - SQL is generated with `reporting_channel = 'briefing_press'`, `basis = 'press_reported'`.
   - Rows are keyed on `(obs_month, reporting_channel, vintage)` to allow updates (revised articles).
   - Applied alongside the 2026 rows already in place.

## Config format

Template in `config/briefing_press_backfill.json` (generated by `scripts/backfill_hedge_ratio_search.py`).

Each row:
```json
{
  "obs_month": "2020-01-01",
  "reported_by": "金管會保險局",
  "sources": [
    {
      "url": "https://money.udn.com/money/story/5613/{ID}",
      "published": "2020-02-XX",
      "outlet": "經濟日報",
      "fields": {
        "hedge_ratio_regulatory": "50.23%",
        "regulatory_fx_exposure": "15.4兆元"
      },
      "quote": "Exact quote from the article with all figures."
    }
  ],
  "note": "Any contextual notes (e.g., interpolated denominator)."
}
```

## Verification workflow

1. Complete `config/briefing_press_backfill.json` with articles and figures.
2. Merge into `config/briefing_press.json` (keep 2026 rows, add backfill rows in chronological order).
3. Run:
   ```bash
   python3 scripts/stage1_briefing_press.py
   ```
4. Check report and log:
   - All 67+ months should appear in `data/sector_monthly_briefing.csv`.
   - All figures verified in `reports/stage1_briefing_YYYYMMDD.json` (verification_failures = []).
   - Identity checks in `out/stage1_briefing_YYYYMMDD.sql` (any with tolerance breaches noted).
5. Apply SQL to Supabase (via MCP).

## Known constraints

- Only month-ends available (no intramonth publication of hedge ratios).
- Year-end denominators only (monthly values for 2020–2024 require interpolation).
- No access to raw briefing transcripts; press articles are the sole source.
- Some outlets (udn.com apex, CNA www root) serve 403 at the proxy; fallback to money.udn.com or secondary sources.
